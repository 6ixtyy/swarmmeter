# SwarmMeter

Usage limits per owner for AI agent swarms, on NEAR.

APIs limit usage per key, but one owner can run 1,000 agents. On NEAR, `agent7.zaki.near` can only be created by `zaki.near`, so SwarmMeter counts usage per owner instead of per key. Named owners get a free tier. Anonymous accounts pay from the first call.

Show who you are, or pay.

Work in progress for the NEAR Hackathon (Nov 2026). Testnet only.
